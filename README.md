# AgSnapTool

Windows 트레이 앱. 지정한 모디파이어를 누른 채 클릭하면 화면의 컨트롤이나 창을 PNG로 찍어 클립보드에 넣는다. 기본 조합은 `Ctrl+Shift+Alt`다.

스냅 갤러리 창은 Tauri다. 실행할 때는 열리지 않는다. 닫으면 프로세스는 트레이에 남고, 종료는 트레이 메뉴에서 한다.

- 좌클릭: 커서 아래 컨트롤
- 좌 드래그: 선택한 사각형
- 우클릭: 그 최상위 창
- 클릭과 영역 드래그는 대상 앱으로는 전달되지 않는다

클립보드에는 실제 PNG 파일(`CF_HDROP`), `PNG` 바이트, `CF_DIB`가 들어간다. 탐색기에서 붙여넣으면 파일이 생긴다.

## 요구 사항

- Windows x64
- WebView2
- [Rust](https://rustup.rs/) 1.85 이상. 이 저장소는 1.99에서 확인했다

관리자로 실행하지 않는다. DPI는 Per-Monitor V2다.

## 빌드와 실행

```powershell
cargo run --bin agsnaptool
cargo build --release --bin agsnaptool
```

릴리스 바이너리는 `target\release\agsnaptool.exe`다. 콘솔 창은 없다. 빌드가 `CHANGELOG.md`를 exe 옆으로 복사한다.

## 스냅 갤러리

트레이 왼쪽 클릭이나 「스냅 갤러리」로 연다. 실행할 때는 열리지 않는다. 창을 닫아도 트레이에 남고, 종료는 트레이 메뉴다. 앱은 하나만 뜬다. 두 번째 실행은 기존 창을 연다.

### 찾기

상단 날짜 목록의 첫 항목은 전체다. 나머지는 캡처가 있는 날이고, 최근이 위다. 전체를 고르면 최신 컷부터 본다. 날짜를 고르면 그날만 남는다.

옆 검색은 태그, 메모, 시각, 날짜를 본다. 갤러리에서 `#`을 누르면 검색칸에 `#`을 넣고 커서가 간다.

화면에 보이는 만큼만 붙이고, 아래로 스크롤하면 다음 묶음을 불러온다. Ctrl+휠로 카드 크기를 바꾼다.

### 카드

폴라로이드 모드가 기본이다. 하단 시각은 밀리초까지다. 태그·메모가 있으면 날짜 위에 붙는다. 테이프는 장마다 노랑, 빨강, 파랑 중 하나고, 모서리 두 장이나 상단 가운데 한 장이다. 길이는 설정값에서 장마다 ±10이고 높이는 그대로다. 끝은 뜯긴 모양이고, 사진보다 벽 쪽으로 더 붙는다. 호버 확대를 켜면 올린 뒤 설정한 대기와 배율로 커진다. 배율은 1.2부터다. 2단계 확대도 따로 켤 수 있다. 2단계 확대는 기울이지 않는다.

폴라로이드 모드를 끄면 기울기와 테이프가 없다.

### 선택과 동작

클릭은 선택이다. Ctrl은 여러 장, Shift는 범위다.

| 입력 | 결과 |
| --- | --- |
| 더블클릭 | 돋보기 |
| Shift+더블클릭 | 돋보기 창 |
| Ctrl+C, 「복사(C)」 | 고른 PNG를 클립보드에 넣는다. 탐색기에서 Ctrl+V로 파일이 생긴다. 한 장이면 `PNG`와 `CF_DIB`도 넣는다 |
| 「태그/메모(T)...」 | 태그와 메모. 여러 장을 고르면 같은 내용이 모두에 들어간다. 태그 칸에서 `#`을 치면 이미 있는 태그를 고른다. `#ag`면 ag로 시작하는 항목만 남는다 |
| 「MD 복사(M)」 | 원본 그림과 OCR 글을 마크다운으로 클립보드에 넣는다 |
| 「MD 저장(S)」 | 같은 폴더에 `.md`를 만든다. 한국어 OCR이 없으면 설치 방법을 알려 준다 |
| 「돋보기(V)...」 | 그 이미지를 크게 본다. 휠로 확대하고, 확대한 뒤에는 왼쪽 버튼으로 끈다 |
| 「편집(E)...」 | 별 창에서 도형과 글을 그린다. 색·선·화살촉·글자 크기는 마지막 값이 다음 기본이다 |
| Delete, 「삭제(D)...」 | 고른 파일을 지운다 |
| 「연결 프로그램으로 열기...」 | 그 파일을 연결 프로그램으로 연다 |

메뉴 단축키는 괄호 글자다. Esc는 메뉴, 돋보기, 대화상자를 닫는다.

### 설정

오른쪽 칸에서 바꾼다. 접기와 펼치기로 접을 수 있다.

| 항목 | 내용 |
| --- | --- |
| 단축키 | 캡처에 쓸 Ctrl, Shift, Alt |
| 지난 캡처 삭제 | 켜면 보관 일수가 지난 `Screenshot-*.png`를 지운다 |
| 언어 | 시스템, 한국어, English |
| 테마 | 시스템, 다크, 라이트, Flat, Material, 글래스. 시스템·다크·라이트는 애플 스타일이다. 상단과 설정에만 적용되고 폴라로이드 사진은 그대로다 |
| 폴라로이드 모드 | 날짜 크기, 기울기, 테이프 보이기, 테이프 길이·높이 |
| 호버 확대 / 2단계 확대 | 대기(ms)와 배율 |
| 변경 내용 | `CHANGELOG.md` |

## 캡처

| 입력 | 결과 |
| --- | --- |
| 좌클릭 | down만 삼킨다. 커서 아래 가장 깊은 가시 컨트롤을 찍는다 |
| 좌 드래그 | 고른 사각형을 찍는다. up은 훅에서 삼키고, move는 딤 창이 대상 앱을 가린다 |
| 우클릭 | down과 up을 삼킨다. 그림자 없는 창 프레임을 찍는다 |
| 더블클릭 | 한 장만 찍고 알림 없이 연다 |
| 한 번 클릭 | 알림만 띄운다. 알림을 누르면 돋보기 창이 열린다 |

좌클릭의 UI Automation 사각형은 창 안에 있고, 한 변이 8보다 크며, 창 면적의 85%(`17/20`) 미만일 때만 쓴다.

## 파일

```text
%LOCALAPPDATA%\AgSnapTool\shots\yyyy-MM-dd\Screenshot-yyyyMMdd-HHmmss.png
%LOCALAPPDATA%\AgSnapTool\settings.json
%LOCALAPPDATA%\AgSnapTool\notes.json
%LOCALAPPDATA%\AgSnapTool\gesture.log
```

설정은 `settings.json` 한 파일이다. 태그·메모는 `notes.json`이다. 캡처를 저장하면 창 제목이 기본 태그로 들어간다.

같은 초는 `-2`부터 붙는다. 캡처는 항상 저장한다. 「지난 캡처 삭제」를 켜면 찍힌 날짜와 오늘 사이의 일수로 센다. 그 차이가 보관 일수 이상인 `Screenshot-*.png`만 실행 때와 1시간마다 지운다. 예전에 `%TEMP%\shots`에 있던 파일은 앱 폴더로 옮긴 뒤 같은 기준으로 본다. 클립보드에 넣은 직후에는 지우지 않는다.
